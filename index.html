How to Link in Worship Tools & OBS

Step-by-step setup guide for live presentation software

1 WorshipTools Presenter Setup

  1. Host this webpage on any free host (like Netlify, Vercel, GitHub Pages, or your web server).
  2. Click "Get Link / URL" at top right and copy your custom setup URL.
  3. In WorshipTools Presenter, open your Service Cue List.
  4. Click + Add Item → Select Web Page item type.
  5. Paste your copied URL into the Web Page URL field.
  6. Save item. When you click this item in your order of service, it will show as a full screen live bouncing logo!

2 OBS Studio / Streamlabs Setup

  1. In OBS, go to your Sources panel and click + Add Source.
  2. Select Browser source.
  3. Paste your URL into the URL field.
  4. Set Width to 1920 and Height to 1080 (or your stream resolution).
  5. Check "Shutdown source when not visible" for performance.

3 ProPresenter Setup

  1. Create a new Slide in ProPresenter.
  2. Add a Web Element to the slide.
  3. Paste the generated URL into the Web Address settings.
  4. Scale the web element to fill the slide canvas area.
